## 🎯 Project Overview

This project presents sales information in a clear, visual Excel dashboard to help users explore performance and identify useful business patterns. It focuses on making sales data easier to understand and supporting data-informed decisions.

## 📌 What This Project Explores

| Analysis area | Questions it can help explore |
|---|---|
| 💰 Sales performance | How are sales performing over time? |
| 🛍️ Product performance | Which products contribute most to sales? |
| 👥 Customer purchasing patterns | What purchasing patterns appear across customers? |
| 📈 Business insights | What trends or opportunities deserve attention? |

## 🛠️ Tools Used

- **Microsoft Excel** — dashboard creation and data analysis
- **Charts and visual summaries** — to communicate patterns clearly

## 🚀 How to Explore the Project

1. Select **Open Excel Dashboard** at the top of this README.
2. Download the workbook using GitHub's download option.
3. Open the workbook in Microsoft Excel.
4. Explore the dashboard, charts, and any available interactive controls.
5. Use the visual summaries to investigate sales and product trends.

## 💡 Business Value

This project demonstrates how spreadsheet-based analysis can turn sales data into a concise visual summary. It is designed to help viewers quickly explore trends, compare performance, and identify questions worth investigating further.

## 👤 About

Created as a data analytics portfolio project to practise Excel dashboarding, data interpretation, and business-focused reporting.
